## Cyber Defenders

### Overview

This repository documents my progress through cybersecurity labs and investigations. Each lab focuses on developing practical skills in areas such as threat detection, malware analysis, digital forensics, network analysis, and incident response.

The goal of this repository is to document my learning process, record investigation findings, and build practical cybersecurity skills relevant to defensive security and Security Operations Centre (SOC) analysis.

### Repository Structure

```text
cyber-defenders/
├── xmlrat-lab/
│   ├── images/
│   └── xmlrat-lab.md
│
└── README.md
```

Each lab has its own directory containing its documentation and supporting evidence. As I complete more labs, I will add new directories using the same structure.

### Skills Development

Through these labs, I aim to develop and strengthen skills in:

- **Threat Detection and Analysis** — Identifying and investigating suspicious activity.
- **Malware Analysis** — Understanding malware behaviour and associated security risks.
- **Digital Forensics** — Examining digital evidence and documenting findings.
- **Network Analysis** — Analysing network traffic and identifying potentially malicious communications.
- **Incident Response** — Understanding investigation workflows and defensive response techniques.

The specific skills and tools used in each investigation will be documented in the corresponding lab directory.

### Documentation Approach

Each lab aims to include, where applicable:

- **Overview** — The purpose and objectives of the lab.
- **Tools Used** — Tools and technologies used during the investigation.
- **Investigation Steps** — The methodology and commands used.
- **Findings** — Observations, results, and analysis.
- **Evidence** — Screenshots and other supporting artefacts.
